# To-Do List App

A simple and clean To-Do List application built using HTML, CSS, and JavaScript. It helps users organize their daily tasks and keep track of what needs to be done.

## Features

- **Add Tasks:** Easily add new tasks to your list.
- **Mark as Completed:** Check a task when it is finished.
- **Delete Tasks:** Remove tasks that are no longer needed.
- **Filter Tasks:** View all, active, or completed tasks.
- **Task Counter:** Keep track of the remaining tasks.
- **Clean UI:** Simple interface with a minimal color combination.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Font Awesome

## How to Run

1. Clone this repository:

   ```bash
   git clone https://github.com/avnish-23/To-Do-List.git
   ```

2. Open the project folder.
3. Open `index.html` in your browser.
4. Start adding and managing your tasks!
